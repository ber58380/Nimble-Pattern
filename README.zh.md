# 灵巧样板

[English](README.md)

Nimble Pattern是[Applied Energistics 2](https://github.com/AppliedEnergistics/Applied-Energistics-2)
的附属模组，对AE2的样板增添了一些功能以提升游玩体验。

## 前置需求

- Minecraft `版本=1.20.1Forge`
- ae2 `版本>=15.4.10`
- JEI `版本>=15.20.0.129`

## 功能

### 样板标记终端

该终端可查看网络内所有样板，支持直接从终端取出样板，返回终端时样板会回到原始槽位。
网格布局下，展示网络内的所有样板。分组布局下，按照样板设置的更新条件分组展示网络内的样板。

### 更新样板

在样板标记终端，可以标记样板的更新条件。当标记的物品进入了ae2网络，若玩家携带了无线终端，
会收到可更新样板的消息提示。

在样板标记终端的分组布局下，如果该分组的样板已经满足了更新条件，标题行右侧会显示出“更新”按钮。
点击该按钮会显示建议采用的新配方，配方优先推荐同机器的其它配方，推荐顺序为：字节数（使用合成材料）更少>产量更高。

**目前该推荐功能只支持GT的相关配方。**

### 模糊合成

为AE2的样板供应器添加了一个模糊卡的升级槽位，装配了模糊升级的样板供应器执行合成时会对输入和输出都执行模糊匹配。

### 假样板

若一个处理样板的产物只有一本被铁砧重命名过的书，则该样板被视为假样板。该样板执行时只要所有输入材料均已被AE2网络成功推送出去，则视为执行完成，不等待产物返回。

编码样板时重复编码可以取消假样板的标记。

### 循环样板

**循环样板仅支持处理样板**。

以超立方体的合成为例，一条合成路径的相关配方为：

```text
10B 富快子时间流体 -> 10B 扩大化空间流体
16 超时空金属杆 + 1B 扩大化空间流体 -> 64 超立方体
1 超立方体 -> 500mB 富快子时间流体
1 超立方体 -> 144mB 液态超时空金属
144mB 液态超时空金属 -> 1 超时空金属锭
1 超时空金属锭 -> 2 超时空金属杆
```

这条合成路径实际上包含了2个循环，整体结构为：

```text
超立方体 -> 富快子时间流体 -> 扩大化空间流体 ---------------> 超立方体
超立方体 -> 液态超时空金属 -> 超时空金属锭 -> 超时空金属杆 -|
```

其中，`超立方体`是两个循环共享的物品，因此入口要标记为`超立方体`，出口则标记`扩大化空间流体`或`超时空金属杆`。
放上`循环存储元件`，即可将这几个样板标记为循环样板。

#### 循环存储元件

循环存储元件是专门用于存储循环样板入口物品的元件，在上例中，循环存储元件会被标记为存储`28 超立方体`。
如果想要尽可能利用GT机器的并行能力，可以在编码时翻倍样板，则循环存储元件也会存储更多的超立方体用于启动循环。

当网络内存在除循环元件外的其它存储元件时，终端不会显示循环存储元件内的物品。仅当网络内只有循环存储元件时，终端可以看到循环存储元件内存储的物品。

循环存储元件物品的输入和输出只能通过`ME IO端口`进行，玩家以及ae2的常规合成都无法取出循环存储元件内的物品。只有执行对应的循环合成时，内部的物品才会被ae2调用。

### 工具样板

**工具样板仅支持合成样板。**

在`样板编码终端`编写样板时，如果有输入物品在合成过程中不消耗，且该物品不会损坏，则样板会自动编码为`工具样板`。
通过重复编码，可以取消掉样板的`工具样板`标记。

除了自动标记的方式，玩家也可以在`样板标记终端`将样板标记为`工具样板`，但同样需遵守工具不消耗且不损坏的要求。
除了常规的工具以外，一些特殊的自增配方也可被标记为`工具样板`，比如`锻造模板`的合成。

### 概率样板

在`样板标记终端`，可以设置合成的最长等待秒数，将样板标记为`概率样板`。
以5s为例，当玩家下单了10个概率物品且对应材料被ae2发出后，开始计时`5*10=50秒`。
50秒后，如果没有合成出10个概率物品，则ae2会自动下单缺失数量的概率物品，并重复该流程直到获得了10个概率物品或因材料缺失无法继续下单。

## 兼容模组

- jecharacters: 样板标记终端内可使用拼音进行搜索
- gtceu, gtlcore, gtladditions, extendedAE: 支持对样板总成系列、分子操纵者、扩展样板供应器和装配矩阵的样板管理
- gtlcore: 兼容图合成功能，仅接管被本模组标记样板的合成

## 特别说明

模组`Inventory Tweaks Refoxed`会在样板标记终端添加一个无用的排序按钮。如果你想移除，将下面的代码添加到config的
`invtweaks-client.toml`文件即可。

```toml
[[sorting.containerOverrides]]
containerClass = "com.ber.nimblePattern.client.gui.PatternTagTermScreen"
sortRange = ""
[[sorting.containerOverrides]]
containerClass = "com.ber.nimblePattern.menu.PatternTagTermMenu"
sortRange = ""
```
